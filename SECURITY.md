# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| latest (`main`) | :white_check_mark: |
| older | :x: |

## Reporting a Vulnerability

Please report security vulnerabilities **privately** — do not open a public GitHub issue.

Preferred: open a private GitHub Security Advisory:
https://github.com/kozliatko/dboard/security/advisories/new

Alternatively, e-mail: jan.vajda@gmail.com

What to expect:

- Acknowledgement within **3 days**.
- An initial assessment within **7 days**.
- A fix or mitigation targeted within **30 days**, depending on severity.

Please use **coordinated disclosure**: give us time to release a fix before any public disclosure.
